延迟和断线问题的实验性解决方案

TCP 微调（Windows）

配置确认应答发送（TCP Ack）

游戏中传输战斗流量使用的是 TCP 协议。这意味着必须为每个到达的网络包发送接收确认，这会产生额外的延迟。更大的延迟来自于确认并不是在收到第一个包后立即发送，而是在收到其他几个包之后才发送，虽然这通过减少确认（Ack）的发送频率降低了接收内容的网络负载，但同时也增加了延迟（网络延迟），这对于游戏来说是致命的。
为了消除这种延迟，建议使用 Leatrix Latency Fix 3 软件，你可以从官方网站下载它[1]。启动程序后，点击 Install 按钮以应用更改，点击 Remove 以撤销更改，之后必须重启系统或者禁用/启用相应的网络适配器。

该实用程序进行的主要配置是为 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\注册表分支下的所有网络接口写入参数 TcpAckFrequency=1

禁用 Windows 内置延迟

从 Windows Vista 版本开始，Windows 操作系统中包含了一个特殊的媒体数据处理机制，它会增加数据包处理延迟（network throttling）以降低 CPU 负载并提高稳定性。为了减少游戏中的网络延迟，你可以尝试禁用此延迟。为此，需要在注册表编辑器中（开始 > 运行 > regedit）打开分支 HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\，并在十六进制编辑模式下将 NetworkThrottlingIndex 参数更改为 FFFFFFFF，然后重启系统。

注意！错误的注册表修改可能会导致系统故障。此外，这可能会在其他应用程序中引发问题，例如在播放流媒体视频时，还会对 CPU 产生额外的负载。因此，如果出现问题，应将此设置恢复为默认值（十六进制模式下的“a”，十进制模式下的“10”）。

家用路由器配置

在解决断线问题方面，端口映射（游戏所使用的端口）取得了极好的积极经验。现代 SOHO 路由器为此提供了两种方案。
注：配置步骤可能会因路由器型号而异。你始终可以在路由器说明书中找到准确的指南。在执行该指南之前，你需要查明你的电脑在局域网中的 IP 地址（通常以 192.168.xx.xx 开头），并将其连同 DNS 服务器一起写入网络连接设置中（或者在路由器的 DHCP 设置中）。

端口映射

在路由器的 NAT / 端口映射（Port forwarding, Virtual servers）选项卡中，需要为每个端口添加多条规则：
Listening port (Service port)：4444、5190、5223、5222、5050
Internal port：4444、5190、5223、5222、5050
IP address：你的电脑地址

或者为端口范围添加一条规则：
Listening port (Service port)：4444-5223
Internal port：4444-5223（或留空）
IP address：你的电脑地址
保存设置后，通常需要重启路由器。

DMZ 主机

此选项类似于将整个端口范围映射到局域网中的特定地址。由于攻击者可能会利用你系统中的漏洞，这可能会降低安全性。
在 DMZ 选项卡中，在提供的字段中输入你电脑的 IP 地址，并在设置允许的情况下启用它。在此之后，通常需要重启路由器。
