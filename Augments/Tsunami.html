Adrenaline 245 000

当坦克严重受损时增加炮塔伤害。
为增强型伤害调制器添加备用电池，仅在坦克的底盘受到致命破坏等极端情况下激活。从两个能量源为伤害调制器供电是不安全的 —— 它可能会爆炸。要求仅在受到严重损坏时才激活它，可能是为了避免保修索赔。
优点
  • 常规伤害和暴击伤害：+25%
缺点
  • 伤害加成仅在生命值≤35%时激活
  • 当坦克带有冷冻状态效果时，该效果将被禁用。


Manual Firing Mode 245,000

关闭第二个炮管的自动射击。
该模式下的射击控制单元工作方式与其他任何炮塔一样。如果您不想改变习惯，这会非常舒适。
优点
  • 炮弹重装时间 -25%
缺点
  • 弹匣容量 = 1

标准射击可以对多个目标造成伤害。
由于炮塔口径有限，爆炸半径不大。但这个效果足以将敌人的人数优势转化为对他们不利的因素。

  • 平均效果半径范围百分比 = 50%
  • 最小效果半径范围百分比 = 50%
缺点
  • 弹丸不再弹跳
  • 爆炸半径伤害可能会造成自身伤害

类星体


采用不可复制技术制成的装备改造。暴击会产生一个量子涡流，同时施加多种效果，通常是负面效果。科学家们设法降低了暴击伤害，但这还不足以挽救局势——一旦遭到打击，敌人仍然会惨败。该技术的发明者名列国际通缉令榜首。
优点
  • 用暴击射击命中敌人将施加以下状态效果：
    • 干扰器：5 秒
    • 电磁脉冲：2 秒
    • 眩晕：1.5 秒
    • 穿甲：9 秒
缺点
  • 暴击几率：-8%
  • 暴击伤害：-90%

炮塔连续发射三发子弹而不是两发。
集成了一个特殊的撞锤，利用两个炮管的后坐力能量。借助它，当第二个炮管开火时，第一个炮管有足够的时间重新装填。
优点
  • 弹匣容量：3
  • 两次射击之间的时间：-60%
  • 后坐力：-25%
缺点
  • 额外连击伤害：0
  • 炮弹重装时间：+25%

Camper


当坦克受到最小伤害时增加炮塔伤害。一个增强型伤害调制器的备用电池，通过人工智能控制的管理系统与主电源并联。该系统安全地将炮塔伤害提升超出调制器的标准能力，但前提是坦克的结构完整性保持完好。如果人工智能检测到底盘遭到破坏，备用电池将立即关闭 —— 当然，这一切都是为了避免保修索赔。
优点
  • 常规和暴击伤害增加：+90%
缺点
  • 伤害加成仅在您拥有至少 95% 的最大生命值时激活。
  • 当坦克带有 冷冻状态效果时，该效果将被禁用。

Excelsior


在不引入新功能的情况下增强关键炮塔或底盘参数。
这款高级装备改造是一项突破性研究计划的成果，该计划将金刚石晶体融入了炮塔的设计中。金刚石涂层的炮管衬里增加了射击时的工作压力。金刚石轴承提高了炮塔的旋转效率。金刚石半导体提升了瞄准系统的计算性能。唯一的缺点？它惊艳的工艺隐藏在炮塔内部，无法被外界看到。
优点
  • 伤害：+30%
  • 转弯速度：+15%
    • 转弯灵活度：+15%
