什么是 FPS


在战斗中显示 FPS 和网络延迟

FPS (frames per second) — 每秒帧数，即帧率。

换句话说，就是游戏画面的刷新频率。该值越高，游戏就越流畅。

每秒帧数显示在战斗中的右下角。您可以在游戏设置的画质选项卡中关闭此功能。

有人认为帧率值取决于网速或服务器负载。这种看法是错误的，因为该指标主要取决于电脑的性能。

如果您的 FPS 较低，请按照以下说明操作。

如何提高 FPS

通用建议

  • 如果 FPS 问题并非由您电脑较低的硬件配置引起，建议按下组合键 Ctrl+Alt+Del，然后按 Esc 以退出弹出的窗口，而不做任何更改。此操作会触发图形上下文的重新初始化，并可能有助于解决低 FPS 问题。
  • 如果您使用的是笔记本电脑，请确保在电源设置中激活了最高性能模式。
  • 确保您安装了最新版本的软件：显卡驱动程序、浏览器。
a）如果您使用的是台式电脑，请从显卡制造商的网站下载驱动程序。
б）如果您使用的是笔记本电脑，请从笔记本电脑制造商的网站下载驱动程序。
  • 打开游戏设置（右上角的齿轮图标），切换到画质选项卡并关闭特效（动态主题、光照、抗锯齿等）。
  • 如果您在浏览器中游玩——请关闭除游戏标签页之外的所有标签页。
  • 关闭所有打开的程序以释放系统资源。
  • 关闭所有使用互联网的程序：即时通讯软件（Skype、Discord 等）和文件下载器（Torrent、Download Manager 等）。如果您使用的是家庭或企业网络，则需要关闭该网络中所有电脑上的这些程序。
  • 尝试通过官方游戏客户端（可从主页下载）或另一个浏览器进行游戏。
  • 如果您的电脑是通过无线连接（3G / 4G / Wi-Fi）连接到互联网的——请尝试有线连接。
  • 尝试按下 F11 键以全屏模式进行游戏。

显卡工具

配备双显卡的笔记本电脑

许多现代笔记本电脑都配备两个显卡——集成显卡和独立显卡。默认情况下，图形处理总是由低性能的集成图形核心处理，因此，正确将处理切换到独立显卡可以显著提高 FPS 甚至是图像质量。

如果您使用的是 NVIDIA 显卡
1. 打开“NVIDIA 控制面板”。可以通过在桌面上点击鼠标右键并从下拉菜单中选择相应选项来完成：

2. 选择“管理 3D 设置”选项。
3. 切换到“程序设置”选项卡。
4. 在第 1 项“选择要自定义的程序”中，添加您用于游戏的程序（浏览器、客户端）。
注意：对于 Firefox，需要添加 plugin_container.exe 而不是 firefox.exe。它位于 Firefox 安装文件夹中（默认路径为C:\Program Files (x86)\Mozilla Firefox\）。
5. 在第 2 项“为此程序选择首选图形处理器”的下拉列表中，选择“高性能 NVIDIA 处理器”。
6. 点击“应用”按钮并关闭控制面板。

如果您使用的是 ATI/AMD 显卡

2. 在“电源”选项卡上，选择“可切换显卡全局设置”。
3. 在所选电源模式下方的下拉列表中，选择“最大性能”：

显卡驱动设置

对于 NVIDIA 显卡：在桌面上点击右键 → “NVIDIA 控制面板” → “3D 设置” → “调整图像设置和预览”。将滑块调至侧重于性能的“使用我的优先设置”。点击“应用” → “确定”。

对于 ATI/AMD 显卡：在桌面上点击右键 → AMD Catalyst Control Center → “标准参数” → “应用用户自定义设置”。在窗口中将滑块调至“性能”。然后选择“多重采样细节级别”选项卡 → 将滑块向左拉 → “性能”。点击“应用” → “确定”。

垂直同步

在显卡设置中关闭垂直同步可能会减少输入延迟。为此，请执行以下操作：

  1. 进入显卡控制面板（见上文说明）。
  2. 找到 3D 图形设置菜单（也可能称为“图形参数”、“3D 应用程序参数”或类似名称）。
  3. 在设置列表中找到与同步对应的项目：“垂直同步” / “垂直同步脉冲” / “同步”。
  4. 关闭垂直同步。

请记住，关闭垂直同步会影响在此操作系统中运行的所有游戏的图形设置。它们都将在没有垂直同步的情况下运行。
