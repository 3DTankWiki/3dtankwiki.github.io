如何增加浏览器缓存

参见： 浏览器和如何理缓存

浏览器缓存是用户已浏览网页的副本。当再次尝试查看这些页面时，浏览器（或代理服务器）将不再从 Web 服务器请求它们，而是从缓存中提取。应用缓存可以减轻网络负载并提高页面加载速度。为了加速加载，游戏会将资源存储在浏览器缓存中，并在需要时从那里获取。为了防止缓存中的资源随时间被挤占，必须增加其最大大小。

增加 Internet Explorer (IE) 和 Microsoft Edge 的缓存

1）启动 Internet Explorer 并进入浏览器菜单（右上角的按钮）并选择 Internet 选项；
2）切换到常规选项卡，在浏览历史记录部分点击“设置”按钮；
3）设置所需的缓存大小（500-1000 MB）：



4）双击“确定”按钮保存所做的更改。

更改 Internet Explorer 的设置也会影响 Microsoft Edge 浏览器（仅在 Windows 10 上可用）。

增加 Mozilla Firefox 的缓存

1）进入浏览器菜单（右上角的按钮）并点击“设置”按钮；
2）在左侧选择隐私与安全部分；
3）勾选停用自动缓存管理并设置你的数值（建议不低于 500 MB）：



4）点击“确定”按钮保存所做的更改。

增加基于 Chromium 内核浏览器的缓存

基于 Chromium 引擎的浏览器列表包括 Chrome、最新版本的 Opera、Yandex 浏览器等。你可以在链接中查看完整列表。

基于 Chromium 内核的浏览器缓存大小修改方法是相同的。
系统本身不提供直接增大缓存大小的功能，因此采用替代方法——在可执行文件的快捷方式中，通过空格添加参数 --disk-cache-dir="с:\browserсache" --disk-cache-size=1073741824。

  • C:\browserсache — 缓存文件夹，用引号括起来，路径可自行选择；
  • 1073741824 — 以字节为单位的缓存大小，在此例中为 1 GB。

以 Google Chrome 浏览器为例说明如何增加缓存：
1）找到用于启动浏览器的快捷方式（例如 Chrome），右键点击它并选择“属性”。
2）切换到快捷方式选项卡，在目标一栏的...chrome.exe"后面输入一个空格，并写入字符串--disk-cache-dir="C:\ChromeCache" --disk-cache-size=1073741824



3）点击“确定”按钮保存所做的更改。
