用途

测试服务器的用途是验证新版本，并在为测试员提供舒适的环境下查找漏洞。
在测试服务器上赚取的水晶、在那里购买的物品以及任何其他游戏资产都不会转移到你在主服务器上的账号中。

如果你在某处“注册”并获得了“邀请码”——你将无法进入游戏的官方测试服务器。多半情况下，你的账号登录名和密码已被“盗取”，过一段时间你可能会发现你的账号因作弊而被封禁或锁定。到那时，你大概不会记得自己曾在诈骗（钓鱼）网站上注册过并亲手交出了密码，而是会认为自己的账号被黑客攻击了。请记住，获取邀请码既不需要密码，也不需要邮箱。如遇账号被盗，请联系客服支持。

大规模测试

有时，验证版本需要大量同时在线的用户。在这种情况下，测试服务器将向所有感兴趣的人开放。关于测试服务器向玩家开放的消息绝不会提前通知。公开测试期间可自由进入。

测试服务器指令

有时，测试服务器上可能会提供一些特殊指令，用于修改测试账号的参数。不过，通常它们仅对开发人员有效。

  • “/addcry n” — 在测试服务器上的当前账号中添加 n 个水晶；
  • “/addxp n” — 在测试服务器上的当前账号中添加 n 点经验值；
  • “/addpremium n” — 为当前账号添加 n 分钟的 VIP。

这些指令在主服务器上无效。如果在测试服务器之外的任何地方尝试使用这些指令，你可能会收到警告或封禁。

交流礼仪

测试服务器上的行为和游戏规则与主服务器上的规则没有任何区别。

如何进入测试服务器

真正的《3D 坦克》测试服务器地址为 https://test.tankionline.com
其他声称的地址都是旨在窃取你账号的骗局！

测试服务器没有固定的开启时间表。

不要忘记，服务器资源是有限的。如果你无法进入测试，请稍后再试。在测试期间，如果需要修复故障或进行更新，服务器可能会被重新启动或暂停。

真正的测试服务器有三种状态：

  • 已关闭。任何人无权访问；
  • 对测试员和测试员候选人开启。进入需要邀请码；
  • 对所有人开启。进入时需要创建一个新账号，或者尝试使用主服务器上的账号密码登录。

如何成为测试员并获取邀请码

有意成为测试员的申请将在论坛上进行审核。如果管理层批准了你加入测试员行列的申请，他们会通过论坛私信通知你。申请批准后，你将成为测试员候选人。此外，那些在论坛上的发言引起管理层兴趣的玩家，无论是否有提交申请，有时也会成为测试员候选人。
