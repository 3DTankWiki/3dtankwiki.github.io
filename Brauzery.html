总则

选择合适的浏览器并进行正确设置是畅玩 3D 坦克的关键。

玩家在使用当前浏览器时可能不会遇到任何问题。然而，在进行一次更新或安装某些插件后，情况可能会发生变化。

为了获得最佳游戏体验（尤其是在配置较低的系统上），建议安装一个专用的浏览器。此方案的优势包括：

  • 拥有独立于其他浏览器的资源缓存，不会被其他不相关的信息挤占。这能加快游戏加载速度。
  • 运行速度快。专为 3D 坦克游戏准备的浏览器无需安装各种插件，也不必打开会加重系统负担的额外标签页。

如果在 Windows 7/8/8.1/10 系统上遇到低帧数问题，可以在进入战斗后尝试通过组合键 Ctrl+Alt+Delete、Esc 来重新初始化图形上下文。此建议适用于任何浏览器。

Google Chrome

Google Chrome 是由知名公司 Google 开发的浏览器，也是全球最受欢迎的浏览器。

该浏览器基于 Chromium 浏览器构建。还有其他几款浏览器也是基于 Chromium 编写的，其中包括 Yandex 浏览器和 Comodo Dragon。因此，Google Chrome 常见的一些问题也可能会在上述浏览器中出现。

您可以从官方网站下载该浏览器的最新版本。

Opera GX

Opera GX 是由挪威 Opera Software 公司专门为游戏玩家开发的一款浏览器。Opera GX 专为玩家打造的独特功能之一，就是能够限制浏览器使用的最大内存（RAM）和 CPU 占用率，从而将电脑的全部可用性能释放给正在运行的应用（游戏）。该浏览器还拥有一个名为 GX Corner 的专区，您可以在其中查看即将推出和已发布的 jogo、游戏行业新闻等内容。


您可以从官方网站下载该浏览器的最新版本。
