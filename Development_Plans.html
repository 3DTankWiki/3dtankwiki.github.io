Development Plans

see also: Main Page and Updates


Attention! This is a list of work-in-progress and planned development. These are only highly considered or mentioned plans, this means that the mentioned items on the list are not definite as plans can change.
Recently Completed
  • Ability to let players change their first nickname for free
  • Add AI tanks or bots
  • Make container opening animation in 3D
  • Magnum's mobile aiming mechanism added to PC
  • New icons
  • Reformat the missions UI
  • Key system (replacing containers as rewards)
  • More turret and hull augments (possibly adding special hull augments that protect from multiple status effects)
  • Tanki Online on Reddit and TikTok
  • Added a battle tutorial for new players
  • Add the possibility of opening a large number of containers at once
  • Add a 3D indicator of the direction of damage received
  • All PC features available in mobile (PRO battles with some alterations, ability to change game language, chat in battles, clans, & promo code redemption)
  • Automatic supply activation on PC (you will have the option to disable it)
  • TO on gamepad
  • Map lighting, shadow quality & graphics improvement (including night maps)
  • TO on Nintendo Switch
  • TO Mobile app on iOS
  • Finish the last HD turret by 2025
  • Contracts (some will increase the drop rate percentage of a specific item from containers)
Work-in-Progress / Planned
  • HD Skins (including Juggernaut & Terminator)
  • Advertising
  • Player profiles rework & achievement rewards in-game
  • Return of Gifts in the garage (including animated ones for premium currency) (only after player profiles appear in-game)
  • Supercharge drops
  • Skins from Tanki X
  • Hovering Juggernaut (when hovering hull equipped)
  • Voice chat (most likely for group members only)
  • New maps (once the new map-building tool is complete and after remastering the current maps)
  • Fix the HTML physics
  • New game mode "bomb-cart" (until bots are improved)
  • Dynamic suspension for hulls
  • Fix in-game lags
  • Multiple account log-in with a single password for easy account switch (including Steam)
  • Return of M0-M3 skins as cosmetics (not in the near future, only when nostalgia hits hard)
  • Server status page
  • Garage decorations for holidays (not until all turrets and hulls are in HD)
  • Indicators that indicate a player is playing on a PC or mobile
  • Self-destruction changed to a warning countdown in maps death zones
  • Make spectator mode available for players (only with a premium account)
  • Equipment presets in the garage
  • Fix the zero-damage bug
  • Add a feature to entertain players during long loading screens
  • Bonus for completing battles consecutively
  • Add weather conditions to maps such as snowfall, falling leaves, and rain (not in the near future)
  • Improve game sounds
  • Icons replacing the rank icon that indicates a player is banned
  • Add a crystal to ruby converter (exchange rate will not be liked)
  • Animated skins
  • New spider hull (will equip with B0NK)
  • Add the Juggernaut mode in PRO battles
  • New shot effects
  • Variety of grenades (Healing, Tesla, Smoke, Magnetic, Countermeasure, Foam, etc.)
  • Improve countermeasures against DDoS attacks
  • Translate the game into more languages
  • All drones in HD and skins for drones
  • New and more optimized client
  • Zombie mode (bots using B0NK vs players)
  • Boss fight game mode (something with interesting mechanics, attack phases, and several shooting options)
  • Improving clan system such as adding its own currency, etc. (only after we complete the tutorial and gain more players)
  • New types of reflective paints (chrome, mirror, and gold)
  • Tanki Classic
