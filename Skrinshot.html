截图

截图（英语 screenshot — 屏幕截图）是指通过按下键盘上的 PrtScr 键（针对全屏）或 Alt+PrtScr 组合键（针对当前窗口）从显示器屏幕获取的图像。操作系统的剪贴板中会保存屏幕截图。随后，所获取的截图可以粘贴到图形编辑器中进行处理和保存。浏览器配有额外的插件，借助它们无需图形编辑器即可获取并保存截图。此外，还有专门用于创建、处理和保存截图的程序。

Windows

使用图形编辑器创建截图

  1. 按下 Alt+PrtScr — 活动程序窗口的图片（例如，如果您在游戏中 — 来自浏览器）将进入剪贴板；
  2. 启动任意图形编辑器。例如，Paint。点击“编辑” → “粘贴”（Ctrl+V）；
  3. 之前制作的窗口图片已粘贴；
  4. 点击“文件” → “另存为”；
  5. 选择文件类型：png 或 jpg；
  6. 点击“保存”。

使用“截图工具”创建截图

在 Windows 7 及更高版本中，存在上述经典截图方法的内置替代方案。它被称为“截图工具”。这是系统预装的一个工具，可以在“开始” → “所有程序” → “附件”菜单中找到。“截图工具”允许您选中所需的屏幕区域并将其保存为图形文件。为了快速调用此工具，您可以为其设置热键或将快捷方式放在方便的位置（例如桌面或任务栏）。

截取截图

  1. 启动“截图工具”；
  2. 启动需要截图的程序；
  3. 点击“新建”。
    通过右侧菜单，您可以选择截图模式 — 全屏、窗口或任意区域；
  4. 制作并保存截图。

Windows 8 和 10：最简截图方法

如果您的操作系统是 Windows 8 及更高版本，您可以使用 Win+PrtScr 组合键截图。全屏截图将自动保存到“图片”文件夹中（其快捷方式通常位于“开始”菜单或“计算机”中）。此方法不需要任何第三方工具。

使用 FastStone Capture 创建截图

FastStone Capture 是一款允许编辑和查看图形文件，以及进行屏幕截图并进行后续编辑的程序。支持所有主流图像格式：BMP、JPEG、JPEG 2000、GIF、PNG、PCX、TIFF、WMI、ICO 和 TGA。内置编辑器允许您旋转、调整大小、更改色深、裁剪片段以及对图像进行其他操作。在截取截图时，您可以使用热键和众多设置，借助它们您可以截取活动窗口、整个屏幕工作区等。

除了常规截图外，FastStone Capture 还可以制作网页的完整截图，即使网页在浏览器中滚动也是如此。提供在截图上添加说明文字、签名、指示箭头和水印的功能。截图区域可任意指定，也可以进行全屏截图。

请注意：该程序为共享软件，试用版仅有效一个月。

截取截图 2

  1. 启动 FastStone Capture；
  2. 启动需要截图的程序；
  3. 选择以下截图方法之一：
    • 点击托盘图标并选择建议的截图方法之一；
    • 使用可在“Settings” → “Hotkeys”中设置的热键；
  4. 制作并保存截图。

网页完整截图

  1. 启动 FastStone Capture；
  2. 启动需要截图的程序（在我们的例子中是浏览器）；
  3. 点击图标；
  4. 按住鼠标左键，将鼠标光标从上往下拖动；
  5. 保存截图。

使用 TechSmith SnagIt 创建截图

该程序的主要用途是从显示器屏幕截取截图。而且 SnagIt 不仅能够拍摄所选区域的静态图形截图，例如还可以将屏幕上发生的事情录制成视频，以及捕获使用 DirectX 的应用程序中的图像。

内置的注释编辑器允许您向截图中添加说明、突出显示某些内容、在需要的地方插入箭头等。此外，程序还允许从无法通过“复制”/“粘贴”命令移动文本的地方“提取”文本。

其他功能：支持与扫描仪和数码相机协同工作，以及自动将程序制作的截图发送到网站。还有许多其他小功能：热键管理、使用预设、从 EXE 和 DLL 中“提取”图标和其他图形、截取需要滚动才能查看的网页截图等等。

请注意：该程序为共享软件，试用版仅有效 15 天。

截取截图：

  1. 启动 SnagIt；
  2. 启动需要截图的程序；
  3. 点击“Start new capture”或按 PrtScr 键（默认）。
    热键可在“Options” → “Preferences” → “Hotkeys”中进行设置；
  4. 选中所需的屏幕区域；
  5. 保存截图。

使用 Joxi 创建截图

Joxi 是一款免费的跨平台截图程序。使用简单，能够将截图上传到自己的托管服务器并提供链接，但有几个缺点：

  1. 开始使用前必须进行注册（通过电子邮件或社交网络）；
  2. 在免费版本中：
    • 上传截图的空间容量限制为 1 GB；
    • 禁用了诸如上传图像直链这样有用的功能；
    • 上传的文件在服务器上仅存储 3 个月。

您可以通过链接下载该程序。

下载并安装后，Joxi 将把自己写入自启动，并在每次系统启动后等待用户操作。Joxi 图标可以在托盘中找到。在程序设置中，您可以指定本地保存文件夹和图像质量（如果选择“高”，截图将保存为。png 格式，否则为。jpg），更改热键。在旁边可以找到已上传文件的历史记录，并在必要时从服务器删除不需要的截图。

截取截图 3

使用以下热键（默认）截图会更方便：

  • Ctrl+PrtScr — 选择屏幕区域。上传前可以在内置编辑器中编辑截图。要上传生成的图像，需要按 Ctrl+Enter 或点击工具栏右侧带勾的绿色按钮。
  • Ctrl+Shift+PrtScr — 拍摄整个屏幕。这里上传前也会出现工具栏。
  • Shift+PrtScr — 立即将整个屏幕的截图上传到服务器，跳过编辑阶段。当您不想在点击上传按钮上浪费时间时非常有用。

上传后，截图的链接将出现在您的剪贴板中。

另一款具有将图像上传到托管服务器功能的截图软件，在您的磁盘上仅占用 8 MB。与 Joxi 不同，它不需要注册，并且以匿名或授权模式将截图无任何限制地上传到流行的 Imgur 托管服务器。您可以通过链接下载 Screenpic。

该程序拥有简单极简的界面。功能包括：

  • 保存截图的本地副本；
  • 上传历史记录；
  • 能够上传已保存到磁盘的文件；
  • 更改热键的功能。

使用 Lightshot 创建截图

Lightshot 是一款完全免费的程序，它静静地呆在托盘里等待被调用，以完成其工作。它直接在 Windows / Mac 环境中运行，不依赖于浏览器版本。支持的图像格式：JPEG、PNG。该程序默认替换 PrtScr 键的处理程序并拦截它以启动自身。用户可以点击并选择他感兴趣的屏幕区域，并且所选区域的大小将显示在选区旁边。它具有用于处理所创建截图的最简单工具。

Apple/Macintosh OS 屏幕截图

使用系统自带功能创建截图

要制作截图，不需要任何特殊的程序。只需知道几个键盘快捷键即可。您可以在计算机设置中查看它们，具体在 System Preferences → Keyboard & Mouse → Keyboard Shortcuts 中：

  • Command+Shift+3：全屏保存为桌面上的文件。
  • Command+Shift+4：所选区域保存为文件。
  • Command+Shift+3+Space：程序窗口保存为文件。

要保存到剪贴板，需要同时按住 Ctrl 键。

使用 Mac OS X Grab 创建截图

为了不用记住热键，您可以使用标准的 Mac OS X Grab 工具。可以通过 Spotlight（电脑中的搜索）输入“grab”来找到它，或者在系统实用工具文件夹中找到它。
Grab 程序极其简单，同时又具备不错的功能。
有四种“拍摄”模式，每种模式都提供了热键：

  • Selection — Shift+Command+A — 选定区域截图；
  • Window — Shift+Command+W — 窗口截图，可以从当前打开的任何窗口中选择；
  • Screen — Command+Z — 全屏截图；
  • Timed Screen — Shift+Command+Z — 定时全屏截图。点击启动计时器按钮后，将开始 10 秒倒计时。在这段时间内，您可以准备屏幕进行拍摄。

截图完成后，Grab 中会出现一个带有生成图像的小窗口，现在可以将其保存到您需要的位置。

还值得注意的是，Grab 可以同时处理多个截图。也就是说，您可以“连拍”多张屏幕截图，然后进行对比并选择最佳的一张。Grab 还能够通过按 Command+C 将其截图复制到剪贴板。

使用 Screenshot Plus 小组件创建截图

能够制作以下类型的截图：

  • 全屏；
  • 延迟全屏；
  • 程序窗口（并且会裁剪掉所有背景，包括窗口顶部圆角下的背景）；
  • 小组件；
  • 屏幕区域。

拍摄完成后，Screenshot Plus 会向您展示它并询问如何处理：删除、重试、保存到桌面或设置中指定的位置。
